# 当前交付与后续边界

已实现本机可运行闭环：认证 HTTP + 手机尺寸 UI、MCP 需求入口、可信配置命令执行器、独立工作区、离线 Agent/测试/PR 适配器测试、取消/超时与重启未知处理。运行方法见 [应用说明](application.md)。

后续需使用者配置并单独验收的环境事项：

1. 用已安装且已授权的真实 Codex/Claude CLI 替换 fake profile，确认参数、账户和费用
2. 为指定测试仓库配置 Git/gh，先看 dry-run 再按授权运行实际 draft PR
3. 按需要部署 TLS 远程入口与 OS/container 隔离；当前本机 trusted-host 不冒充生产多租户沙箱
4. 观察实际使用后再决定开发/审查角色组合和更丰富任务历史，不提前引入证据平台、宿主依赖图或动态插件

这些是环境接入和扩展边界，不把已经请求的本机应用实现留作空泛 follow-up issue。
